# Feuille de route · saison 2

16 épisodes, 5 phases. Chaque épisode suit le même cycle : spécifier, générer, vérifier, intégrer.

## Phase 1 · Fondations

| Ép. | Titre | Livrable |
|---|---|---|
| 5 | Devenir développeur prompt engineer | Méthode, cahier des charges validé |
| 6 | Architecture et installation | Structure du dépôt, Docker Compose, premier lancement |
| 7 | La base SQL Server | Modèle de données, scripts de création, données de test |

## Phase 2 · Back-end

| Ép. | Titre | Livrable |
|---|---|---|
| 8 | L'API clients et produits | Endpoints FastAPI CRUD, validation |
| 9 | Tests et débogage | Tests pytest, corriger un bug avec l'IA |
| 10 | Connexion et rôles | Authentification, droits par rôle |
| 11 | Ventes et factures | Commandes, calcul des totaux, factures PDF |
| 12 | Stock et alertes | Mouvements de stock, seuils, alertes |

## Phase 3 · Interface

| Ép. | Titre | Livrable |
|---|---|---|
| 13 | L'interface React | Structure de l'application, navigation, connexion |
| 14 | Les écrans métier | Écrans clients, produits, ventes, stock |

## Phase 4 · Analyses

| Ép. | Titre | Livrable |
|---|---|---|
| 15 | Les analyses SQL | Requêtes d'analyse (CA, top clients, rotations de stock) |
| 16 | Tableaux de bord | Graphiques et indicateurs, filtres |
| 17 | Partage des analyses | Liens de partage, export PDF |

## Phase 5 · Production

| Ép. | Titre | Livrable |
|---|---|---|
| 18 | Qualité et revue de code | Revue de code avec l'IA, refactorisation, sécurité |
| 19 | Mise en production | Déploiement, configuration, sauvegardes |
| 20 | Examen final et certification | Examen et certification de la formation |
